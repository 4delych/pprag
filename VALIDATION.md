# Проверка реализации

Дата: 27 октября 2026 года. Среда: Windows, Python 3.12, локальное виртуальное окружение `.venv`.

- `python -m pytest -q`: 12 проверок прошли. Использован настоящий embedded Qdrant; нейросетевые модели подменены явным тестовым адаптером.
- `python -m compileall -q rag_demo scripts tests`: успешно.
- `docker compose config --quiet`: успешно, структура Compose корректна.
- Docker Desktop установлен, но его движок не смог запуститься. Ollama на `127.0.0.1:11434` отсутствует. Поэтому контейнерное развёртывание, настоящие embeddings, нейросетевая генерация и интерфейс AnythingLLM в этой среде не проверены.

Изображения кода сняты с содержимого реальных исходных файлов средствами подсветки синтаксиса. Схемы запуска и AnythingLLM являются объясняющими иллюстрациями, а не скриншотами успешного запуска. В докладе нет выдуманных измерений точности или задержки. Для получения воспроизводимых нейросетевых результатов предусмотрен `scripts/evaluate.py`; он требует работающей Ollama и построенного индекса.
