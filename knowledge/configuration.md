# Конфигурация TaskBoard 1.0

## Порт приложения

По умолчанию TaskBoard использует порт 8000. Чтобы сменить порт на 8080, задайте APP_PORT=8080 в .env и используйте uvicorn app.main:app --port 8080. Аргумент --port должен совпадать с выбранным значением APP_PORT.

## Подключение к базе

DATABASE_URL задаёт адрес PostgreSQL. Для локального окружения используется база taskboard. После изменения схемы выполняйте alembic upgrade head. Не храните настоящие пароли в репозитории.

## Версия документации

Все файлы этого набора описывают TaskBoard 1.0. Для новой версии приложения подготовьте отдельный согласованный снимок документации.
